# Tripo: the props for Floors 10 to 18, temples, clubs and castles

The new floors, the temples (Floor 7 onward), the hidden clubs (every floor) and Castle Dread are built from these. The game already asks for these names. Until each one exists that spot stays empty, so the more you make, the fuller the floors get.

**Settings:** same as before (text tab, H3.1 Best Quality, 4K, PBR off, Triangle). Polycount by size:

- **Big:** 40,000
- **Mid:** 20,000
- **Small:** 8,000

**Saving:** `art/incoming/props/<folder>/<folder>.glb`, then tell Claude "import the props".
