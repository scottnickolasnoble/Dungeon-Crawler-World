# Tripo: props, weapons and vehicles

These replace the block-built Blender stand-ins that show up most around the maps, plus the first held weapons and the cars you'll be able to get into.

**Settings** (same as the characters): Model > text (pencil tab), Geometry & Texture **4K**, **PBR off**, **Triangle**, polycount **40000** (use **20000** for the small props marked *small*), AI Model **H3.1 Best Quality**.

**Saving:** Export > GLB 4K, saved as **art/incoming/props/<folder>/<folder>.glb**. Then tell Claude "import the props". The *height* line is what the importer scales each one to; you don't need to type it into Tripo.

Every prompt starts with the same style line, so the props match the cast.

---

## A. Weapons (held in first person)

These are what you see in your hand, so they matter most. Each weapon type swings differently in game: blunt swings sideways, blades slash diagonally, polearms thrust and heavy weapons do slow overhead chops. Enchantments (fire, frost, storm and so on) are added in the game as glowing effects, so make one plain version of each. Transmog will reuse these models.
