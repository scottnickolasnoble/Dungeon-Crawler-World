# Tripo: the comic kit (detail for every floor)

This list is about **density and character**. Comics never have an empty wall or a bare corner, so this kit covers:

- building-front pieces that cover the plain box walls
- clutter to fill every street and camp
- dressing for the new hills
- one or two signature pieces per floor

It's separate from `TRIPO_PROPS.md` (weapons, vehicles, camp basics). Do that list first if you haven't.

**Settings:** same as before (text tab, H3.1 Best Quality, 4K, PBR off, Triangle). Use these polycounts:

- **Big:** 40,000 (building pieces, landmarks)
- **Mid:** 20,000 (furniture-sized things)
- **Small:** 8,000 (clutter, placed by the hundred)

**Saving:** `art/incoming/props/<folder>/<folder>.glb`, then tell Claude "import the props". The *height* line is for the importer only; don't paste it into Tripo.

**Every prompt below already includes the style line.** It asks for the ink outlines to be painted into the texture, which is what makes props sit inside the comic look rather than on top of it.
