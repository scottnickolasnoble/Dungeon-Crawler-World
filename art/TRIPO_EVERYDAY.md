# Tripo: everyday props (replacing my block-built ones)

Every desk, box, lamp, bin and shelf in the game was built by Claude out of simple shapes in Blender. There are 258 of them. This list swaps the most-seen ones for proper Tripo models.

**How the swap works:** save each one with the **folder name shown**, which is the name the game already uses. Then tell Claude "import the everyday props". The importer will:

- scale each new model to the exact size of the one it replaces
- stand it on the floor and face it the same way
- drop it in everywhere that prop appears, on every floor, with no placement work

You don't need heights; the old prop sets the size.

**Settings:** same as before (text tab, H3.1 Best Quality, 4K, PBR off, Triangle). Polycount **20,000** unless marked *small* (8,000) or *big* (40,000).

**Saving:** `art/incoming/everyday/<folder>/<folder>.glb`.

Every prompt includes the same style line, with ink outlines painted into the texture so the props match the comic look.

Props already in `TRIPO_PROPS.md` (loot box, tent, bonfire, barricade, lamp post, bench, trolley, manhole, wrecked car and others) aren't repeated here.
