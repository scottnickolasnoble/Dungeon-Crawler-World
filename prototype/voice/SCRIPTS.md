# Downstairs — voice recording scripts

Record each line as a separate file named exactly as shown (`.wav` or `.mp3`, mono is fine). The game can play your recordings instead of the synthetic voices, and apply a different voice effect per character (pitch, formant, growl, robot, echo) so one person can play everyone.

Tips: record in a quiet room, ~15 cm from the mic, leave half a second of silence at each end. Act it big; the effects work better on clear, energetic reads.
