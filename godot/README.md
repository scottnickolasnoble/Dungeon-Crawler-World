# Downstairs: Godot project

Godot 4.7 (Standard build), Forward+ renderer. Open this folder's `project.godot` in Godot and press F5.

## Layout
- `data/`: game data as JSON, generated from the prototype. Read in game through the `Data` autoload.
- `models/`: `.glb` models generated from the prototype. `monsters/library/` and most of `npcs/` aren't placed in the game yet.
- `scenes/`, `scripts/`: the game itself.
- `shaders/`: `ink.gdshader` (ink lines and hatching) and `toon.gdshader` (comic shading and surface paint).
- `models/props/`, `textures/`: Floor 0's art, generated by `tools/blender/build_landing_kit.py` and `tools/paint_landing_textures.mjs`.

Don't edit `data/` or `models/` by hand while the prototype is still the source of truth, because re-exporting overwrites them. To regenerate them, from the repository root:
```
cd prototype && npm install && cd ../tools && npm install && cd ..
node tools/export_prototype.mjs
```

## Checks
Run with the Godot console executable, from this folder:
```
Godot_console.exe --headless --import
Godot_console.exe --headless -- --autotest
Godot_console.exe -- --shots=C:/some/folder
```
`--autotest` checks the data and the player's movement and collisions. `--shots` opens a window, saves screenshots of Floor 0 and quits.

## Not converted yet
- **Dialog trees** (Phase 3): they're code in `prototype/game/story.js`, not data, so choices that run code become named actions.
- **Shops** (Phase 3): each shop is a function that builds its stock from game state.
- **Walk cycles** (Phase 6): the exported models are static. The prototype animates them with a vertex shader, which doesn't carry over.

## Before exporting a build
Add `data/*.json` to the export preset's non-resource include filter, or the JSON files won't be packed.
